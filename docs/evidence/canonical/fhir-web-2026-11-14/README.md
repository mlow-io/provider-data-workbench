Clinic mappings, recipes and validated-dataset controls are absent from the native workspace; backend enforcement is unchanged.

Reference acceptance/rejection uses the native policy, expected attempt and one request ID per exact submitted intent. Reconciled field provenance shows contributing resource paths and raw source-network context, with no inferred local network binding. The optional panel loads as a separate JS chunk.
